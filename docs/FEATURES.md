# MiniMonitor

一个类似 TrafficMonitor 的 Windows 置顶悬浮窗监控工具，但**只显示 4 项核心信息**，界面更干净：

| 项目 | 显示示例 | 单位说明 |
|---|---|---|
| 下载速度 ↓ | `12.3 M` | M = **MB/s（兆字节/秒）**，不是 Mbps（1 MB/s = 8 Mbps） |
| 上传速度 ↑ | `1.5 M` | 同上，MB/s |
| CPU 温度 | `55 度` | 摄氏度，取 CPU Package / Tctl 温度 |
| GPU 温度 | `48 度` | 摄氏度，取 GPU Core 温度（NVIDIA / AMD / Intel 核显） |

效果：屏幕上一个圆角小窗（默认右下角，可拖到任意位置），置顶常驻，右键可切换网卡、透明度、配色、开机自启。

**默认显示（开机自启，CPU/内存/显存/运行时长/开机时间默认开启，右键菜单可开关）**：

| 项目 | 显示示例 | 说明 |
|---|---|---|
| CPU 占用率 | `52%` | 总占用百分比，PerformanceCounter 读取 |
| 内存占用 | `8.2/16G 51%` | 已用/总量 GB + 使用百分比 |
| GPU 专属显存 | `3.2/6.0G 53%` | Dedicated VRAM 已用/总量 GB + 百分比，多卡显示总和（总量：注册表 qwMemorySize → DXGI → nvidia-smi；使用量：WDDM 性能计数器 → nvidia-smi） |
| 运行时长 RUN | `2天 05:12` | 本次开机以来运行的时间（默认开启，≥1 天显示 `N天 HH:MM`，不足 1 天显示 `HH:MM:SS`） |
| 开机时间 BOOT | `10-31 08:12` | 本次开机时间（默认开启，右键菜单可关闭） |

开启后悬浮窗自动增加对应行，无需重启。

## 功能特性

- 软件自带图标（CPU 芯片 + 右侧温度计，深色圆角底），exe / 窗口 / 托盘统一显示
- 网速按**字节（MB/s）**显示，默认自动累加所有物理网卡（已排除 VMware / Hyper-V / VPN / Tailscale 等虚拟网卡），也可手动指定单张网卡
- **温度多路径读取，兼容 Windows 10 / 11 / Server 2016 ~ 2025**（详见下文"温度读取原理"）
- CPU 占用率、内存占用、GPU 专属显存、运行时长、开机时间默认开启显示，右键菜单可随时开关
- 温度变色预警：≥75℃ 橙色、≥85℃ 红色；读不到时显示 `-- 度`
- 运行时长/开机时间：WMI 读取系统开机时间（LastBootUpTime），挂起休眠恢复后依然准确，WMI 不可用时自动回退
- **XShell 复刻版（默认只在点击时打开，位于“FluentRSS阅读器”上方）**：在 MiniMonitor 中内置一个 XShell 8 风格的终端工具，界面参考 XShell 8，会话能力参考 [Tabby 1.0.238](https://github.com/eugeny/tabby) 并剔除官方信息收集代码。默认 **深色界面**，支持 **浅色 / 跟随系统** 自动切换；渐变品牌区、圆角悬停按钮、柔光阴影、圆角标签与渐变状态栏。支持 SSH / Telnet / 串口 / 本地 PowerShell 四类会话、xterm.js 终端仿真（UTF-8 / GB18030）、会话管理器（分组增删改、搜索、会话新建 / 属性 / 复制 / 删除、JSON 导入导出，默认隐藏，点击显示）、多标签终端、快速会话栏（预置 master / node1-3 等一键连接按钮，默认显示）、独立 SFTP 双栏窗口（Xftp 风格，无需 Xftp）、密码 / 私钥 / 键盘交互认证、主机指纹确认、跳板机、本地 / 远程 / 动态端口隧道、手动会话日志（`文件 → 日志` 或终端右键 → 日志）、五种终端配色、字号缩放与全屏。**复制粘贴严格使用终端右键菜单**：选中文字后右键 → 复制，右键 → 粘贴；SSH / Telnet / 串口 / 本地 Shell 一致，Ctrl+C 始终发送中断字符。密码使用 Windows DPAPI 加密保存在 `文档\MiniMonitor\xshell`
- **FluentRSS 阅读器（默认只在点击时打开，位于“硬件信息查看”上方）**：在 Windows 原生 WinForms 中复刻 [Fluent Reader v1.3.2](https://github.com/yang991178/fluent-reader) 的三栏阅读体验——左侧订阅源与分组、中间文章列表（列表 / 卡片 / 杂志 / 紧凑四种视图）、右侧 WebView2 内置文章视图；打开窗口时默认最大化，并立即同步一次。支持添加网址自动发现 RSS / Atom / JSON Feed、OPML 导入导出、未读与星标筛选、正则搜索、抓取全文、加载原文网页、自动处理规则、后台定时同步（默认 60 分钟，可调 5 分钟 ~ 24 小时或从不，关闭阅读器后仍继续）、新文章托盘通知与完整数据备份还原；也可连接 Fever / Google Reader API 服务（FreshRSS、Tiny Tiny RSS、Miniflux、The Old Reader、BazQux、Inoreader）。详见下文“FluentRSS 阅读器”
- **离线音乐播放器（默认只在点击时打开，位于“FluentRSS阅读器”下方）**：在 Windows 原生 WinForms + NAudio 中复刻 [WaveFlow v1.9.1](https://github.com/InstaZDLL/WaveFlow) 的本地音乐播放器——默认扫描 Windows 用户音乐目录，支持专辑 / 艺术家 / 流派 / 文件夹 / 喜欢音乐 / PerfectMusic / 播放列表多视图、虚拟化曲目列表与搜索、标签编辑、本地 LRC 同步歌词、6 段均衡器、随机与循环、A-B 循环、睡眠定时、M3U 导入导出、听歌统计、同名重复音乐清理、迷你播放器与桌面歌词插件。窗口首次打开默认最大化，支持拖动四边/四角调整大小，并自动记住下次打开的大小与位置。**默认全离线**：SSDP/DLNA 通告默认关闭，必须在音乐设置页手动开启；不包含账号、Discord / Last.fm / Deezer 等外部服务，也没有遥测。迷你播放器与桌面歌词默认开启，可在标题栏随时切换/关闭。音乐目录下存在 `PerfectMusic` 文件夹时，其中曲目会自动加入“喜欢音乐”并单独展示
- **硬件信息查看**：右键菜单一键打开硬件信息窗口，支持**“精简 / 详细”视图切换**——精简视图为鲁大师式一页概览（最上方依次为系统型号/系统序列号，其后为操作系统/处理器/主板/内存/显卡/磁盘/显示器/网卡/声卡/电池/运行状态各一行关键信息，多个并列值每行一条、不使用分号，内容过长时单元格自动换行完整显示）；详细视图为 Excel 风格分组表格，全量查看操作系统（含 TPM 支持/规范版本/制造商/固件版本/PPI 版本/启用/激活/拥有状态；检测不到时自动给出多路径诊断：ACPI 设备枚举、启动模式、TBS 服务状态与 BIOS 排查建议）/ 处理器 / 内存 / 主板与 BIOS / 显卡（含最高刷新率）/ 显示器（含最高刷新率）/ 磁盘 / 分区卷 / 网络适配器 / 音频设备 / 电池 / 系统运行状态等分类（默认不占任何界面，点击菜单才弹出），两个视图均支持搜索过滤与一键复制（TSV，可直接粘贴进 Excel）；精简视图顶部的“系统型号 / 系统序列号”支持单击复制到剪贴板，并提示复制成功或失败
- **自定义关机（默认关闭，需手动开启）**：支持 15 分钟 / 30 分钟 / 1 小时 / 1.5 小时 / 2 小时、3 小时 / 6 小时 / 12 小时 / 24 小时 / 2 天、3~7 天快速预设；支持日历 + 时钟选择或直接输入指定日期时间；支持自定义时长（默认 10 秒）；设置后弹出倒计时窗口，可随时取消，到点执行强制关机
- **磁盘安全覆写（默认关闭，需手动开启）**：自动排除当前系统盘；列出非系统物理磁盘及型号、序列号、容量、接口、分区数（优先读取存储设备描述符，缺失时用 WMI 兜底）；支持随机数 1 遍、全零 1 遍、DoD 5220.22-M 3 遍、Gutmann 35 遍；提供可开关的 AES-256 随机密钥加密预覆盖（默认开启，关闭后仅执行所选算法）；需输入 `WIPE 磁盘号` 二次确认；覆写期间显示进度、速度和剩余时间，并允许中止
- **NTP 时间同步（默认自动开启）**：每 5 分钟向主服务器 `edu.ntp.org.cn`、备用 1 `ntp.aliyun.com`、备用 2 `time.cloudflare.com` 校时并校准本机时间；右键 → NTP 同步管理可查看/开关自动同步、上次同步结果和最近 100 条记录（最新在上，超出自动清理）
- **全局鼠标手势（默认开启，可手动关闭）**：仅一个手势——按住鼠标右键向下、再向右滑动，松开后关闭鼠标所在窗口；浏览器中关闭当前标签页（Ctrl+W），资源管理器/其他软件中关闭当前窗口；全局生效。**在 VMware 系列软件（Workstation / Player / Remote Console / Horizon）窗口内自动临时失效**，完全不拦截右键，虚拟机内的右键菜单和操作不受影响；移出 VMware 窗口后自动恢复。输入捕获参考 GestureSign V2 18.4.3 的模型：`WH_MOUSE_LL` 安装在主 UI 线程的消息循环中，并额外启用 `GetAsyncKeyState` 轮询后备，防止钩子回调被系统/安全软件拦截时完全失效；为保证鼠标响应速度，日志记录能力已移除
- **磁盘分析管理（默认不显示，手动点击打开）**：扫描磁盘或指定文件夹，按目录聚合大小，显示文件夹占用矩形图、最大文件夹和最大文件排行；可随时停止，结果可双击在资源管理器中打开；窗口支持最大化/还原，最大化时工具栏、概览、矩形图和列表都会自适应铺满
- **全盘数据恢复（默认不显示，手动点击打开，托盘菜单位于“Navicat 复刻版”下方，主菜单位于“磁盘分析管理”和“截图插件”之间）**：窗口默认最大化，内置五个选项卡。Kickass Undelete 复刻：选择 NTFS / FAT 卷，扫描 $MFT 记录与 $Bitmap 簇位图（FAT 读取目录项），列出已删除文件名、原路径、大小、修改时间、恢复几率、MFT 记录号；支持筛选、排序、全选、批量恢复，恢复文件按原目录结构输出到另一块磁盘。FreeRecover：按文件签名扫描并恢复图片、视频、音频、文档与压缩包。TestDisk：枚举物理磁盘，解析 MBR / EBR / GPT 分区表，显示分区类型、文件系统、起始 LBA 与大小；支持备份 / 恢复分区表、搜索丢失的 NTFS / FAT / ext 分区候选，写入分区表前需要二次确认。PhotoRec：按 JPEG / PNG / GIF / BMP / TIFF / WebP / PDF / ZIP / RAR / 7Z / OLE / SQLite / MP3 / MP4 / AVI / WAV / MKV 等文件签名深度雕刻恢复，可限定扫描大小或全盘扫描。WinfrGUI调用系统工具：自动检测并调用 Microsoft Store 的 Windows File Recovery（winfr.exe），支持常规 / 广泛 / NTFS / 段 / 签名模式、文档 / 图片 / 视频 / 音频 / 压缩包 / 邮件筛选、/n 自定义筛选、/y 签名类型、/a /u /k /g /e /o /p /s /b 开关、命令预览、实时日志、进度解析与中止，未安装时可一键打开 Microsoft Store
- **截图插件（默认不显示，截图与录屏默认开启）**：`Ctrl+Shift+C` 矩形截图（默认自动复制到剪贴板并打开编辑器）；`Ctrl+Shift+W` 滚动截图（长网页 / 长文档）；`Shift+PrintScreen` / `Shift+F9` 开始/停止录屏。支持全屏、活动窗口、矩形、圆角矩形、椭圆、自由手绘、多边形、滚动窗口截图、延迟与多显示器；内置图像编辑器支持裁剪、箭头/矩形/椭圆/文字、高亮、模糊、马赛克、智能擦除、水印、边框、圆角、撤销/重做；水印可设置字体、字号、颜色和加粗，默认微软雅黑、加粗、紫色 #FF0080，字号默认“自动（当前）”沿用原有按图片宽度计算；编辑器底部“复制”左侧提供 **OCR识别** 按钮，调用 Windows 系统内置 OCR（离线本地识别，不上传图片），优先使用简体中文语言包，识别结果会按 OCR 单词的边界坐标重建原图排版（缩进、分栏、表格列），在等宽字体可编辑窗口中显示并可一键复制；若系统未安装 OCR 语言包会提示到 Windows 设置中安装；录屏支持全屏/区域、MP4/GIF、帧率/质量、系统或麦克风音频、光标高亮与点击涟漪。MP4 需要 ffmpeg.exe，GIF 使用内置编码器
- **图片处理（默认不显示，手动点击打开）**：右键菜单 → 图片处理，位于截图插件下方、关于上方；窗口支持最大化/还原。所有选项卡导出默认剔除 EXIF/GPS（单张/批量中可手动开启保留）。内置五个选项卡：单张照片处理（旋转/翻转/框选裁剪/按百分比、最长边、宽度或指定宽高缩放/亮度、对比度、饱和度与滤镜/格式与质量导出）、证件照处理（标准一寸、小一寸、大一寸、标准二寸、小二寸等常用规格预设，物理尺寸/像素/DPI 联动，可先框选裁剪原图去掉多余元素，发丝级自动背景抠图并可替换红/蓝/白/浅蓝/灰底，可手动开启复杂背景抠图——多聚类背景/人物颜色模型 + 马尔可夫随机场标记，只保留人像与衣物，适合纹理、杂物或光照不均背景，JPG/JPEG、24 位 RGB、文件大小 10–200KB 区间控制，导出默认自动剔除全部 EXIF/GPS）、批量处理（批量缩放、格式转换、压缩质量、命名规则、保留 EXIF，后台执行并可取消）、照片打印处理（打印机/纸张/方向/份数/每页 1·2·4·6·9 张/页边距/间距/适应·裁剪·拉伸/文件名，逐页预览与打印）、EXIF 信息查看与剔除（查看全部拍摄信息、GPS 定位提醒、一键剔除全部 EXIF 或仅移除 GPS，剔除时自动按方向摆正）
- **通用格式转换（默认不显示，手动点击打开）**：右键菜单 → 通用格式转换，位于图片处理下方、关于上方；窗口支持最大化/还原。内置图片、音频、视频三个选项卡，支持批量添加文件/文件夹与拖放，可设置输出目录、格式、图片质量、音频比特率、视频质量/分辨率，转换在后台执行并可取消。图片支持 JPG/JPEG、PNG、APNG、BMP、GIF、TIFF、ICO、WebP、AVIF，以及 PSD/PSB、XCF、CDR、RAW（CR2/NEF/ARW/DNG 等）、AI、EPS（PSD 解码合成图，其他格式优先提取内嵌预览/缩略图；EPS/AI 缺少预览时会自动调用已安装的 Ghostscript）；音频支持 MP3、WAV、FLAC、M4A、OGG、Opus、WMA、AIFF，并可从视频提取音轨；视频支持 MP4、MKV、MOV、WebM、AVI、GIF、WMV、FLV、TS。音频、视频及 WebP/AVIF/APNG 需要 ffmpeg.exe（可在程序目录、PATH 或窗口底部指定）。资源管理器右键“通用格式转换”菜单默认关闭，可在转换器窗口底部开启（Windows 11 在“显示更多选项”中查看）

## XFTP 客户端（界面参考 Xftp 8，传输行为参考 FileZilla）

右键菜单 → **XFtp复刻版**（位于“XShell复刻版”下方、“FluentRSS阅读器”上方，默认只有点击才打开）；也可以在 XShell 复刻版的 **工具 → XFtp 复刻版**、**帮助 → XFTP 客户端** 或功能区“XFtp”按钮中打开。窗口默认深色主题，可独立使用。

**界面**

- Xftp 风格菜单栏、图标工具栏、渐变品牌标题栏、本地 / 远程双栏、路径栏、底部传输队列与状态栏；工具栏、快速连接栏、传输队列、状态栏均可在 **查看** 菜单中切换。
- **快速连接功能默认关闭**：工具栏不显示“快速连接”按钮，文件菜单也不显示快速连接项；可在 **工具 → 设置** 中启用。启用后快速连接栏仍默认隐藏，可通过查看菜单或 `Ctrl+Shift+F` 打开。
- 快速连接栏、传输队列与状态栏默认隐藏；开始上传 / 下载时传输队列会自动展开显示实时进度，也可在 **查看** 菜单中固定显示。
- 窗口默认不出现在 Windows 任务栏，可从悬浮窗右键菜单或 XShell 复刻版重新唤起；需要任务栏按钮时可在 **查看 → 在 Windows 任务栏显示** 开启。
- 深色主题覆盖菜单、右键菜单、工具栏、输入框、下拉框、列表与自定义表头、滚动条、提示气泡、传输队列、站点管理器、输入 / 确认对话框与 Windows 深色标题栏。
- 双栏列表显示名称、大小、类型、修改日期与权限；本地驱动器下拉框、远程路径栏、上级 / 刷新 / 新建文件夹 / 重命名 / 删除 / 上传 / 下载按钮。
- 未连接远程站点时，右侧不再是空白或系统浅色底，而是完整的深色空状态页（图标 + “尚未连接远程站点” + 连接提示）。
- 本地栏首次打开默认定位到用户目录下的 `Downloads`（兼容 `Download`，不存在时回退到“文档”）；SFTP 会话未指定远程目录时默认进入 `/opt`，无权限或不存在时自动回退到登录目录。
- **与 XShell 复刻版联动**：在 XShell 中点击 XFtp 时，自动带入当前 SSH 会话的主机、端口、账号、密码 / 私钥、跳板机信息并直接连接；远程目录优先使用终端 shell 当前目录（OSC 7 → SSH 只读探测 → 终端标题回退），本地目录固定打开用户目录下的 `Downloads`。如果当前不是 SSH 会话，则打开普通的 XFtp 窗口。

**连接与协议**

- 支持 **FTP**、**显式 FTPS**（AUTH TLS + PBSZ 0 + PROT P）与 **SFTP**（密码 / 私钥 / None 认证，支持 SSH 跳板机）。
- 被动模式优先 EPSV，回退 PASV（兼容 NAT 返回内网地址的情况）；`OPTS UTF8 ON`；优先 MLSD，回退 Unix / DOS 格式 LIST。
- **快速连接栏**：协议、主机、端口、用户名、密码，连接或保存为站点。
- **站点管理器**：站点名称、协议、主机、端口、账号、密码、远程 / 本地默认目录；密码使用 Windows DPAPI 加密，数据保存在 `文档\MiniMonitor\xftp`。

**文件操作与传输**

- 上传 / 下载文件与整个目录（递归）；新建文件夹、重命名、删除（远程目录递归删除）。
- 拖动本地文件 / 目录到右侧远程窗格上传；拖动远程文件 / 目录到左侧本地窗格下载；从资源管理器拖入远程窗格上传；双击远程文件下载。
- 传输队列显示方向、文件名、已传输 / 总大小、实时速度、渐变进度条与状态：成功为绿色 `Success`，上传失败为红色 `uploadfail`，下载失败为 `downloadfail`；支持“取消全部”和“清空已完成”。
- 上传 / 下载使用安全的临时文件下载（`.xftp.part`，成功后改名），失败或取消不会留下半成品文件。

## FluentRSS 阅读器（Fluent Reader v1.3.2 原生复刻）

右键菜单 → **FluentRSS阅读器**（位于“硬件信息查看”上方，默认只有点击才打开）。窗口默认最大化，打开时会立即同步一次；关闭窗口只是隐藏到托盘，后台仍按设定间隔抓取。

**阅读与订阅**

- 筛选搜索：全部 / 未读 / 星标筛选；普通搜索与正则搜索，可区分大小写与搜索正文。
- 自动规则：按“全部 / 分组 / 订阅源”设置正则，命中标题或正文时自动标为已读、加星标、隐藏或发送通知；设置页提供规则测试。

**同步策略**

- 默认 **每 60 分钟**后台同步一次，可在“选项 → 应用偏好 → 自动抓取频率”中改为 5 / 10 / 15 / 30 / 45 分钟、2 / 4 / 8 / 12 / 24 小时或“从不”。
- MiniMonitor 启动后即开始计时；**即使从未打开阅读器、或已关闭阅读器窗口，后台仍按该间隔同步**。
- **每次手动打开 FluentRSS 阅读器都会立即同步一次**，保证打开即最新。
- 支持 ETag / Last-Modified 条件请求、4 路并发抓取、每个订阅源独立的失败记录与重试；新文章可按设置弹出托盘通知，点击通知直接打开阅读器。

**服务同步（可选）**

- 默认“本地 RSS”，无需账号；也可在“选项 → 同步服务”切换为 **Fever API** 或 **Google Reader API**，用于 FreshRSS、Tiny Tiny RSS（Fever 插件）、Miniflux、The Old Reader、BazQux、Inoreader 等兼容服务。
- 服务模式会拉取服务端订阅源与文章，并把本地的已读 / 星标状态推回服务端；密码使用 Windows DPAPI（当前用户）加密保存在配置中，不存明文。
- Inoreader 如需自定义 API Key，可填写 AppId / AppKey；Google Reader 服务使用标准 ClientLogin 认证。

**关于窗口**

右键菜单 → 关于：重新设计的 Fluent 风格关于窗口，大号版本号（当前 v1.66.4），功能说明改为 Excel 风格分类表格，按“悬浮窗监控 / 硬件与系统 / 安全与维护 / 效率工具 / 网络工具 / XShell 复刻版 / XFTP 客户端 / 内置 Web 服务 / FluentRSS 阅读器 / 离线音乐播放器 / Navicat 复刻版 / 其他”十二大类分组，可滚动、搜索、双击复制单行或一键复制全部（TSV，可直接粘贴进 Excel）。

- 播放列表：新建、重命名、删除、右键添加曲目、M3U / M3U8 导入、M3U 导出。
- 听歌统计：曲目 / 专辑 / 艺术家数量、音乐总时长、播放次数、累计收听时长与 Top 曲目 / 艺术家 / 专辑排行，全部来自本地播放记录。

## 温度读取原理（v1.1 多路径回退）

CPU 温度按以下顺序自动回退，**任意一条读到即显示**：

1. **LibreHardwareMonitor**（Package / Tctl / 核心温度）— 最精确，但依赖内核驱动（WinRing0）：无管理员权限、杀软拦截、Secure Boot 阻止、虚拟机内都会失败
2. **WMI 性能计数器** `Win32_PerfFormattedData_Counters_ThermalZoneInformation` — Windows 10 1809+ 系统内置，无需任何驱动，直接返回摄氏度
3. **WMI ACPI 热区** `MSAcpi_ThermalZoneTemperature` — 更老系统也有，开尔文换算（热区温度通常比 CPU 实际温度略低几度）

GPU 温度回退顺序：**LibreHardwareMonitor → nvidia-smi**（NVIDIA 卡，5 秒节流）。

> 结论：即使某台机器的内核驱动被拦（常见于 Windows Server，其安全策略默认更严），程序也会自动改用 Windows 内置 WMI 通道继续显示温度；只有虚拟机（没有真实温度传感器）才会出现所有路径都读不到的情况。

## 常见问题

**Q：Windows Server 2025 上 CPU 温度显示 `-- 度`？**
- 程序会依次尝试 LHM → WMI 性能计数器 → WMI ACPI 热区，常见原因：
  - **LHM 初始化失败（驱动被拦）**：Server 的 Secure Boot / 杀软策略更严，最常见。程序已自动走 WMI 后备，若 WMI 有值则悬浮窗应已显示。
  - **WMI 也读不到**：先确认是**物理机还是虚拟机**（虚拟机没有真实温度传感器，任何软件都读不到），再看 CPU 型号。
  - **CPU 是 Xeon / EPYC 等服务器型号**：部分新服务器平台 LHM 支持不全，但 WMI 热区通常仍可读。
- 若仍为 `--`，可通过“硬件信息查看”确认硬件型号与系统状态。

**Q：为什么 Server 上温度数值比 Win11 上低几度？**
- 回退到了 WMI ACPI 热区通道：热区温度反映的是整机散热区，不是 CPU 核心的精确值，通常低 3~10℃，这是 Windows 内置通道的固有口径，属正常现象。

**Q：网速一直是 0.0 M？**
- 右键 →"网卡选择"，手动选你正在联网的那张网卡（无线选 WLAN、有线选以太网）。

**Q：显示的 M 和测速软件的 Mbps 对不上？**
- 本软件显示的是 **MB/s（兆字节）**。例如显示 `12.3 M` ≈ 98 Mbps；宽带 1000M（Mbps）理论峰值约 125 M（MB/s）。这是有意设计：日常下载软件（浏览器、迅雷、Steam）显示的都是 MB/s。

**Q：开机自启后为什么要点一次 UAC？**
- 开机自启通过任务计划程序（最高权限）实现，登录时不会再弹 UAC。手动双击运行本程序时，因温度读取需要管理员权限，仍会弹一次 UAC；不点"是"也能启动，温度会自动走 WMI 后备，仍能显示。

**Q：全屏看视频 / 玩游戏时悬浮窗还在遮挡？**
- “全屏自动隐藏”默认开启：只要前台窗口铺满整块显示器（网页 / 视频全屏、游戏、播放器、幻灯片放映等），悬浮窗会立即自动隐藏，退出全屏后自动恢复，全程不抢焦点。
- 若仍显示，请右键 → 确认“全屏自动隐藏”处于勾选状态。
- 判定基于“获得焦点的前台窗口覆盖整块显示器”：若全屏程序没有焦点（例如双屏场景下焦点仍在另一块屏幕的普通窗口），则不会触发隐藏，此时手动隐藏到托盘即可。
